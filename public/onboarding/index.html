Getting started

Set up FinOpsWay and your first cluster

A short path from installing the extension to seeing the cost of a Databricks cluster in its own page navigation.

  1. Install
  2. Connect
  3. Create cluster
  4. Check costs
1

Install

Add FinOpsWay to your browser

Install the extension from your browser’s store. No FinOpsWay account is required.

Available for Google Chrome Get the extension ↗ Available for Microsoft Edge Get the extension ↗ Available for Mozilla Firefox Get the extension ↗

Microsoft Edge uses the Chrome Web Store listing.

2

Connect

Connect your Databricks workspace

  1. Open any page in your Databricks workspace, then open the FinOpsWay extension options.
  2. Select the workspace you are using.
  3. Paste a personal access token for that workspace. Browser session mode is also available for testing.
  4. Select a SQL warehouse that can query system.billing and system.compute.
Browser session mode: use at your own risk Session mode reuses the active Databricks session in your browser. It can be convenient for testing, but is not recommended for production use. Use a personal access token for a clearer, more predictable production setup.

The extension only makes read-only queries to your workspace. Your token is stored locally in the browser and is sent only to that workspace.

3

Create

Create and configure a cluster

  1. In Databricks, go to Compute and select Create compute.
  2. Give the cluster a clear name, choose its access mode and select the Databricks Runtime your workload needs.
  3. Choose an instance type and worker range that fits the job. Enable autoscaling when the workload varies.
  4. Set an auto-termination period so idle compute is stopped automatically, then create the cluster.
Cost tip Start with the smallest practical worker range and a short auto-termination period. You can adjust both after observing the workload.
4

Verify

Check the cluster cost

Open the new cluster’s page. The FinOpsWay cost chip appears in the top navigation; select it to see the cluster’s cost, SKU breakdown and the coverage period.

Billing data is not instant. FinOpsWay marks hours that Databricks has not reported yet, so they are never mistaken for zero cost.
