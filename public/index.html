Every cost tool hides those hours. This one draws them.

Databricks billing reports on a lag, so a window that ends at now is part empty by construction. FinOpsWay is a free browser extension that puts one number in your workspace navigation, scoped to the page you are on, and ends its window where the data actually ends. The missing hours are hatched, never padded with silence.

See it

One chip in the workspace navigation, and the whole answer a click below it.

  1. The chip, in the nav $3.13 for the workspace over the 24 h to 18:00 - and how old that is, because a cost number without an as-of is half a number.
  2. Click for the breakdown 24 h, 7 d and 14 d of the same scope. The heading names what you are looking at: workspace, by SKU.
  3. The hatch is the lag Billing stopped at 18:00, so the hours since are drawn hatched rather than filled with a zero.
  4. Every SKU, with a comparison Each line against the same window a period earlier, so the total arrives with something to measure it against.

The last line of that panel is the extension talking about its own limits: the window ends at 18:00, billing has not reported the 4 h since. That is a real workspace, not a mockup.

What it does

Scoped to the page

On a cluster, SQL warehouse, job, job run, pipeline or pipeline update page the chip answers for that resource, with the workspace as its denominator. On the home page, the workspace alone. An unrecognised page falls back to workspace scope rather than to a blank chip.

A real query, from your browser

It runs read-only SQL against the system.billing and system.compute tables from the browser itself. No backend, no OAuth flow, nothing to deploy. The credential is a workspace personal access token you paste into the options page, or optionally the browser session you already have.

Free, structurally

With no servers there are no costs to recover, so free is not a tier, it is architecture. No account, no trial, no telemetry, nothing to sell. The toolbar's own price tag is the one thing in your workspace that reads $0.

Where it runs

Clouds
Databricks on AWS (*.cloud.databricks.com) and Azure (*.azuredatabricks.net). Everything above the hostname is identical on both.
Browsers
Chrome, Edge and Firefox, as a Manifest V3 extension. Available in the Chrome Web Store (Chrome and Edge) and on Firefox Add-ons.
Credential
A workspace personal access token, pasted into the extension's own options page. It never leaves the browser.

Get it

FinOpsWay is available in the Chrome Web Store and on Firefox Add-ons. It is free and does not need an account.

Add to Chrome Add to Edge Add to Firefox

Edge users install from the Chrome Web Store. After installing, open the extension's options page, choose your workspace and paste a personal access token (or use your existing browser session). Then open any Databricks page and the cost chip will appear in the top navigation. Questions? Email us.

Your data

The extension has no backend and no telemetry. Nothing it reads leaves your browser except the query itself, which goes to the Databricks workspace you are already signed in to. We operate no server, receive no data, and have no way to see what you query.

Data the extension handles is used only to display your Databricks spend, which is its single purpose. None of it is sold, transferred to third parties, or used for advertising. The cloud machine prices ship inside the extension, so estimating what your clusters cost contacts no cloud provider either. Read the full privacy policy.
