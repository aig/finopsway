Databricks Genie Agent Costs

FinOpsWay shows DBU usage beside Genie Agent names. A DBU, or Databricks Unit, measures service usage. A usage badge tells you how much was consumed, not necessarily how much you owe.

Is Genie Agent usage free?

As checked on October 6, 2026, Databricks says Genie Agents usage by users is free through January 31, 2027. Service principals, the identities used by automated services, are excluded and billed.

Genie Code has different rules. Check the official Genie billing documentation before applying an allowance or promotion to your usage.

How to review agent usage

  1. Connect FinOpsWay and open Genie Agents.
  2. Read the DBU badge beside an agent. Check the badge details for its reporting period.
  3. Compare similar periods and workloads. Check which identity ran the agent before interpreting usage as a charge.

Example: The screenshot shows 4.35 DBU over seven days for one agent. That means 4.35 usage units, not $4.35. The displayed promotion text is a snapshot; current billing rules take precedence.

Common questions

Why can I see DBUs when usage is free?

Databricks records free usage too. Its free-usage billing category has no list price. Usage can therefore be visible without a corresponding charge.

Can I multiply all Genie DBUs by one dollar rate?

No. First distinguish free and billed usage and the Genie product involved. Applicable rates and billing terms determine the monetary amount. Private discounts are not reflected by FinOpsWay.

Billing can lag by several hours. Check the reported period and freshness. How FinOpsWay calculates costs.
