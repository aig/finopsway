What makes up an all-purpose cluster cost?

All-purpose clusters combine Databricks DBU usage with cloud virtual machine charges. The DBU rate is one part of the cost. The machines running the cluster are billed separately by the cloud provider.

Published all-purpose cluster rates

Public reference rates in USD. Cloud infrastructure is a rough on-demand cost per VM hour. The final rate depends on cloud, region, node size, plan and contract.

How to review an all-purpose cluster

  1. Connect FinOpsWay and open Compute.
  2. Read the reported cost and DBU usage beside the cluster.
  3. Check node type, worker count and Auto Termination before changing the configuration.

Common questions

Does stopping a cluster remove every charge?

It stops new DBU and cloud machine usage for that cluster. Other workspace services can still have their own charges.

Why is the estimate different from the invoice?

Cloud region, private terms and billing freshness can change the final amount.

Billing can lag by several hours. Check the reported period and freshness.
