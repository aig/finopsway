Databricks Serverless Cluster Costs

See serverless DBU usage in context with the workload, performance mode and reporting period.

How is serverless compute billed?

Databricks manages the infrastructure for serverless compute. Usage is billed in DBUs and the applicable SKU depends on the workload, such as notebooks, jobs or pipelines.

Use the billing system table to review serverless usage. Multiple records can belong to one workload, so compare the summed DBUs for the same period.

Published serverless compute rates

Public reference rate in USD per DBU. Serverless infrastructure is included in the DBU rate. The final rate depends on cloud, region, plan and contract.

Common questions

Can serverless usage appear after a workload ends?

Yes. Billing data can arrive later, so check freshness before comparing recent runs.

Can I use one DBU rate for every serverless workload?

No. The SKU and rate vary by workload type, cloud and region.

Billing data can lag. Check the reported period and freshness.
