Databricks Job Cluster Costs

Classic job clusters are scheduled compute. Their spend is made up of Databricks usage and the separate cloud machine costs that run the cluster itself.

What adds up for a job cluster?

Classic job clusters use a Databricks DBU rate and a cloud infrastructure charge. The DBU line captures usage of Databricks compute. The cloud portion reflects the underlying VM or instance that supports the cluster.

All-purpose clusters and job clusters share the same pattern. Databricks usage is only one part of the total. The cloud provider charges for the compute machines separately.

How to review job cluster spending

  1. Open the Jobs or Compute areas in Databricks.
  2. Check whether the workload uses classic cluster compute or serverless compute.
  3. Review job duration and cluster size. Classic clusters add the machine charge on top of DBU usage.

Example: A short daily job on a classic cluster can look inexpensive at the DBU level, but the cloud machine cost still appears in the total. Review both parts before reducing spend.

Common questions

Why is my cloud bill higher than the DBU total?

Because classic compute includes separate cloud infrastructure charges. The Databricks DBU amount does not replace the VM cost, it sits beside it.

Does this apply to all-purpose clusters too?

Yes. Classic all-purpose clusters and classic job clusters both add cloud machine spend. Serverless compute is different because the underlying infrastructure is managed by Databricks.
