What can a run cost help you investigate?

A run-level view gives you a starting point when an execution takes longer or processes a different amount of data. Review its cost with its duration, input volume and compute configuration. A more expensive run may have processed more data, so cost alone is not an efficiency measure.

How to compare two runs

Choose runs with comparable work and check that billing has arrived for both. Review their compute context before drawing a conclusion. If one execution uses shared compute, read the attribution limitations before treating its number as the full cost of that execution.

Get started in your workspace

Install FinOpsWay for Chrome, Edge or Firefox. Follow the setup guide to configure your workspace connection and access. Then open the relevant Databricks page to see the cost context.

Common questions

Why is the latest run missing some cost?

Billing data arrives after usage. A completed run can still have incomplete recent billing. Check the freshness indicator and return after the missing data has arrived.

How should I interpret the displayed number?

Recent billing can arrive with a delay of several hours. Check the period and freshness indicator. Displayed costs are not an invoice and do not include private discounts. Read the cost methodology for calculation and attribution limits.
