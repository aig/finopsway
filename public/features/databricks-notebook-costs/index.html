What does notebook cost context mean?

A notebook uses compute that may also serve other work. The cost visible in that context helps you understand spending around the resource. It does not make every dollar a charge attributable to the current notebook, query or cell.

How to use the view during an experiment

Before comparing experiments, check the compute resource, reporting period and billing freshness. Review whether other workloads used the same resource. Use those details to explain the number before deciding that a code change increased or reduced cost.

Get started in your workspace

Install FinOpsWay for Chrome, Edge or Firefox. Follow the setup guide to configure your workspace connection and access. Then open the relevant Databricks page to see the cost context.

Common questions

Can I see the exact cost of each notebook cell?

This feature provides cost context in the notebook interface. It does not promise an exact per-cell bill or complete attribution for shared compute.

How should I interpret the displayed number?

Recent billing can arrive with a delay of several hours. Check the period and freshness indicator. Displayed costs are not an invoice and do not include private discounts. Read the cost methodology for calculation and attribution limits.
